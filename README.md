# Task Manager App

A Flutter-based Task Manager application developed as part of an Ostad assignment. The application provides user authentication, task management, profile management, and API-based task operations.

## 📱 Project Overview

The Task Manager App is designed to help users create, manage, update, and organize their daily tasks through a simple and user-friendly interface.

The application integrates the provided Task Manager REST API and implements the required authentication and task management functionalities.

## ✨ Features

* User Registration
* User Login
* Password Recovery
* OTP Verification
* Password Reset
* User Profile Update
* Task Creation
* Task List
* Task Status Management
* Task Status Count
* Task Update
* Task Deletion
* Loading State Handling
* Error Handling
* API Integration
* Splash Screen with custom logo
* User-friendly navigation and interface

## 🔌 API Integration

The application is integrated with the provided Task Manager API.

**Base API URL:**

```text
https://task-manager-api.ostad.live/api/v1
```

### Available API Operations

* Registration
* Login
* Recover Verify Email
* Recover Verify OTP
* Recover Reset Password
* Task Status Count
* List Task by Status
* Create Task
* Delete Task
* Update Task Status
* Profile Update

## 🚀 Getting Started

### Prerequisites

Make sure the following are installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Git

### Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd task_manager_app
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
